# atividade-guiada-aula-06-frameworks-1

Aplicação da atividade guiada com React, Vite e React Router.

## Executar

```sh
npm install
npm run dev
```

## Verificar

```sh
npm run lint
npm run build
```

## Rotas

- `/`: página inicial.
- `/sobre`: sobre nós.
- `/contato`: página de contato.
- `/produtos`: lista dos três produtos.
- `/produtos/:id`: nome e preço do produto, mensagem para produto não encontrado e link para voltar à lista.
